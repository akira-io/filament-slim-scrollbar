# Roadmap

## Current Features

### Custom Scrollbar Styling
- Slim scrollbar design (4px width/height)
- Light and dark mode support
- Automatic Filament theme integration
- No configuration required

## Planned Features

### Customization Options
- Configuration file for scrollbar dimensions
- Color customization through config
- Per-panel scrollbar styling
- Disable/enable per component

### Browser Support
- Firefox scrollbar styling (currently webkit only)
- Fallback styles for non-supporting browsers

### Advanced Features
- Different scrollbar styles per theme
- Animation and transition options
- Scrollbar visibility behavior (auto-hide)
- Custom scrollbar track patterns

### Developer Experience
- Artisan command for publishing assets
- Builder pattern for inline customization
- Blade directive for component-level control

### Integration
- Support for custom Filament themes
- Integration with Filament plugins
- Third-party theme compatibility

## Non-Goals

This package does NOT aim to:
- Provide JavaScript-based scrollbar replacement
- Affect scrolling behavior or performance
- Add scrollbar features beyond styling
